# Leads Tracker (Chrome Extension)

Allows users to save leads with just the click of a button

## Features
- allows to manually enter the leads or save from currently active tab
- uses localStorage to store the leads
  - so it's available throughout the tabs
  - available even after page refresh
- on click of saved leads profile, opens up in new tab
- hosted on Netlify
